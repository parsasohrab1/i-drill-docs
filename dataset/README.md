# Dataset

The dataset CSV files (`newone.csv`, `sensor_extended_processed.csv`, `sensor_readings_extended.csv`,
`sensor_readings_noisy.csv`) are already committed in this folder — you do not need to generate
them to get started.

Running `Scripts/Dataset.py` (or `Scripts/Advanced_Dataset.py`) is only needed if you want to
regenerate or refresh the dataset (e.g. with new parameters or additional noise/samples), not to
obtain it for the first time.
