# Archived dev tools

The scripts and text files in this folder are one-off helpers that were used during an earlier
pass of git history rewriting (rewording specific commit messages via interactive rebase,
`filter-branch`/sequence editors, etc.). They reference specific commit hashes from that past
cleanup and are not part of the running i-Drill product (backend, frontend, or ML pipeline).

They are kept here for reference only, in case similar history-rewriting work is needed again.
Do not wire them into CI or any application code path.
